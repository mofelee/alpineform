## 摘要

- 此 prerelease 不完整。已签名 tag 和 asset 会继续发布以便审计，并由
  `v0.1.0-alpha.4` 取代。
- AlpineForm 为持久化 Alpine 3.24 host 提供可 review 的 validate、plan、apply 和 check
  闭环。
- 真实 Alpine 3.24.1 x86_64 VM 门禁覆盖完整 Beta core。
- 四个静态 CLI archive 随 checksum、SBOM、Sigstore verification、GitHub provenance 和
  checksum-verifying installer 一起发布。

## 兼容性

- Release 阶段：alpha；不承诺 stable 兼容性。
- CLI artifact：Linux 和 macOS，支持 amd64 和 arm64。
- Beta 被管理目标：Alpine 3.24 x86_64。
- Preview 被管理目标：Alpine 3.24 aarch64；没有阻塞式真实 VM 门禁。
- 此 release 取代不完整的 alpha.1 和 alpha.2 prerelease。不涉及 AlpineForm state
  migration。

## 破坏性变更

- 相对于 alpha.2 code 或 state format，没有破坏性变更。

## 迁移说明

- 不要使用 alpha.1 或 alpha.2 release artifact。请直接安装 alpha.3。
- 在后续 alpha 升级前，请备份 `/var/lib/alpineform/state.json`。

## 新增

- Alpine fact discovery、root SSH、原子 state、可续期 lease、确定性 plan、原生 Alpine
  resource、经过验证的预构建 component，以及去重 change script。
- 阻塞式 no-op、drift、repair、lifecycle、secret 和 reboot VM 断言。
- 已签名 release checksum、逐 archive SPDX SBOM、GitHub attestation，以及
  checksum-verifying installer。

## 变更

- 在构建 snapshot 或发布前检查 release eligibility。
- 在当前 plan 下，公开仓库符合使用 GitHub artifact attestation 的资格。

## 修复

- 使用 release workflow 调用的 command name 安装 Cosign。
- 保留失败的 prerelease，不移动 tag 或替换部分 asset，然后以新版本发布修正。

## 安全

- Protected value 不会出现在 plan、graph、state、HTML、debug、error 和上传的 integration
  diagnostics 中。
- Component artifact 和 release archive 在使用前均验证 checksum。

## 已知问题

- Alpine 3.24 aarch64 目标支持为 Preview，因为缺少真实 VM 门禁。
- 自定义 APK signing key 和 CA-certificate component 具有 unit/provider 覆盖，但未进入
  阻塞式 VM fixture。
- 此 alpha 不发布 Homebrew。
- 所有 publisher 和 platform verification job 均通过，但最终 summary 未找到嵌套在
  artifact 目录下的 result file。未发布自动化 verification matrix。
- Docker（#10）、具备回滚安全性的 nftables（#13）和目标侧 source build（#14）仍是
  v0.1 core 之外的独立 follow-up。

## 验证

- Commit CI 和 release dry-run 已通过。
- Archive publication、checksum、SBOM、Sigstore bundle、GitHub provenance、Linux 和 macOS
  installer，以及 fresh Alpine 3.24.1 quickstart 均已通过。
- Release workflow 只在最终 result aggregation 阶段失败。
